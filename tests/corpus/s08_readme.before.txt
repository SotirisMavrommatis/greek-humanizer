# fastgrep

Το **fastgrep** είναι ένα εργαλείο γραμμής εντολών γραμμένο σε Rust, σχεδιασμένο για γρήγορη και αποδοτική αναζήτηση κειμένου σε μεγάλα αρχεία. Αξιοποιώντας παράλληλη επεξεργασία και memory-mapped αρχεία, το fastgrep προσφέρει έως και 3x μεγαλύτερη ταχύτητα σε σύγκριση με το παραδοσιακό grep.

## Χαρακτηριστικά

- ⚡ **Υψηλή απόδοση** μέσω πολυνηματικής επεξεργασίας
- 🔍 **Υποστήριξη regex** με πλήρη συμβατότητα PCRE
- 🎨 **Χρωματισμένη έξοδος** για καλύτερη αναγνωσιμότητα
- 📁 **Αναδρομική αναζήτηση** σε φακέλους

## Εγκατάσταση

```
cargo install fastgrep
```

Συνεισφορές είναι πάντα ευπρόσδεκτες! Μη διστάσετε να ανοίξετε ένα issue ή pull request.
