# fastgrep

Το **fastgrep** είναι ένα εργαλείο γραμμής εντολών γραμμένο σε Rust για γρήγορη αναζήτηση κειμένου σε μεγάλα αρχεία. Χρησιμοποιεί παράλληλη επεξεργασία και memory-mapped αρχεία και είναι έως και 3x ταχύτερο από το παραδοσιακό grep.

## Χαρακτηριστικά

- **Υψηλή απόδοση** μέσω πολυνηματικής επεξεργασίας
- **Υποστήριξη regex** με πλήρη συμβατότητα PCRE
- **Χρωματισμένη έξοδος** για καλύτερη αναγνωσιμότητα
- **Αναδρομική αναζήτηση** σε φακέλους

## Εγκατάσταση

```
cargo install fastgrep
```

Συνεισφορές είναι ευπρόσδεκτες: ανοίξτε ένα issue ή pull request.
