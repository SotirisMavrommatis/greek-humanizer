# greek-humanizer

[![tests](https://github.com/SotirisMavrommatis/greek-humanizer/actions/workflows/tests.yml/badge.svg)](https://github.com/SotirisMavrommatis/greek-humanizer/actions/workflows/tests.yml)

Agent skill που αφαιρεί από **ελληνικά** κείμενα τα σημάδια ότι τα έγραψε AI και τα ξαναγράφει ώστε να διαβάζονται φυσικά, χωρίς να αλλάζει τα γεγονότα.

Τα γνωστά humanizer skills (π.χ. [blader/humanizer](https://github.com/blader/humanizer)) είναι φτιαγμένα για αγγλικά. Τα ελληνικά κείμενα από AI έχουν δικά τους σημάδια:

- μετοχή στο τέλος της πρότασης: «…, ενισχύοντας έτσι…», «…, υποδεικνύοντας ότι…»
- γραφειοκρατική σύνταξη: «σε ό,τι αφορά», «στο πλαίσιο της», «μέσω της χρήσης», αλυσίδες από γενικές
- «Επιπλέον… Επιπρόσθετα… Ωστόσο… Παράλληλα…» στην αρχή κάθε πρότασης
- «διαδραματίζει καθοριστικό ρόλο», «αποτελεί ακρογωνιαίο λίθο», «αποτελεί» αντί για «είναι»
- σκελετός «Στο πολιτικό πεδίο… Στο διεθνές επίπεδο…»
- αγγλικά εισαγωγικά αντί για «», κεφαλαίο σε κάθε λέξη των τίτλων, «ScienceDaily ScienceDaily» από αντιγραφή παραπομπών

## Εγκατάσταση

**Claude Code (plugin)**
```
/plugin marketplace add SotirisMavrommatis/greek-humanizer
/plugin install greek-humanizer@greek-humanizer
```

**Claude Code (χειροκίνητα)**
```bash
git clone https://github.com/SotirisMavrommatis/greek-humanizer.git
cp -r greek-humanizer/skills/greek-humanizer ~/.claude/skills/
```

**Claude.ai:** κάνε zip τον φάκελο `skills/greek-humanizer` και ανέβασέ τον από τις ρυθμίσεις Skills.

**Άλλα εργαλεία (ChatGPT, Gemini, Cursor κ.λπ.):** επικόλλησε το περιεχόμενο του `SKILL.md` στις custom instructions.

## Χρήση

```
/greek-humanizer
[το κείμενο]
```

ή απλά: «Κάνε αυτό το κείμενο να μην ακούγεται σαν AI».

- **Μόνο review:** «Κάνε μόνο review», για λίστα με τα προβληματικά σημεία χωρίς ξαναγράψιμο.
- **Με δείγμα γραφής:** δώσε 2–3 παραγράφους δικές σου, και το skill γράφει με το δικό σου ύφος.

## Τι κάνει και τι δεν κάνει

- **Δεν προσθέτει γεγονότα.** Αν το αρχικό είναι αόριστο, το αποτέλεσμα μένει αόριστο. Τα λάθη περιεχομένου (π.χ. «βαθιά ύπνωση» αντί για «βαθύς ύπνος») τα αναφέρει χωριστά.
- **Αλλάζει όσο χρειάζεται.** Ένα κείμενο με 2–3 μοτίβα παίρνει 2–3 διορθώσεις. Οι υπόλοιπες προτάσεις μένουν ως έχουν. Αν το κείμενο είναι ήδη φυσικό, το λέει και δεν το πειράζει.
- **Σέβεται το είδος του κειμένου.** Απρόσωπη σύνταξη σε επιστημονικά κείμενα, επίσημη προσφώνηση σε επιστολές, hashtags σε posts, bold ετικέτες σε λίστες README.
- **Δεν προσθέτει αγγλισμούς** που δεν υπήρχαν στο αρχικό.

## Αυτόματος έλεγχος

Το `skills/greek-humanizer/scripts/check.py` μετράει τα μοτίβα ανά 100 λέξεις και ελέγχει αν χάθηκαν αριθμοί ή ονόματα:

```bash
python3 skills/greek-humanizer/scripts/check.py κείμενο.txt          # βαθμολογία
python3 skills/greek-humanizer/scripts/check.py πριν.txt μετά.txt    # σύγκριση
```

Ο έλεγχος πιάνει μόνο λέξεις και δομές, όχι το αν ένα κείμενο διαβάζεται φυσικά. Είναι μέτρο για το πόσα μοτίβα έμειναν, όχι ανιχνευτής AI.

## Δοκιμές

```bash
python3 tests/run.py
```

Ο φάκελος [`tests/corpus`](tests/corpus) έχει 33 ζεύγη (9 από πραγματικές απαντήσεις του ChatGPT και του Gemini) πριν/μετά σε 20+ είδη κειμένου: έκθεση, αίτηση εργασίας, κριτική προϊόντος, εργαστηριακή αναφορά, Instagram, παράπονο, tech blog, ιστορία, απάντηση chatbot, motivation letter, εξήγηση αναδρομής, συμβουλές, ταινία, ξενοδοχείο, email σε συνάδελφο, LinkedIn, έκθεση ιδεών, README, απάντηση σε forum, περίληψη διπλωματικής, e-shop, μήνυμα Viber, μεγάλη εργασία ~500 λέξεων, και ένα κείμενο γραμμένο από άνθρωπο. Το `tests/controls` έχει ανθρώπινα κείμενα που ο έλεγχος πρέπει να βαθμολογεί χαμηλά. Το GitHub Action τρέχει τα τεστ σε κάθε αλλαγή και αποτυγχάνει αν μείνουν μοτίβα, αν προστεθούν αριθμοί, ή αν αλλάξει κείμενο που δεν είχε κανένα μοτίβο. Τα αποτελέσματα και τι άλλαξε σε κάθε γύρο είναι στο [`tests/RESULTS.md`](tests/RESULTS.md).

## Για τους AI detectors

Το skill δεν είναι ρυθμισμένο με βάση AI detectors. Στις δοκιμές μας, ο ZeroGPT έβγαλε **100% AI** σε σύντομα email γραμμένα από άνθρωπο (με τυπογραφικά λάθη και όλα) και μόνο 72% σε ένα κείμενο γεμάτο AI κλισέ. Στα ελληνικά τα αποτελέσματά του δεν σχετίζονταν με το αν ένα κείμενο ακούγεται ανθρώπινο. Αν το skill ρυθμιζόταν ώστε να ρίχνει αυτό το ποσοστό, θα έγραφε χειρότερα κείμενα.

## Συνεισφορά

Αν βρεις μοτίβο που λείπει, άνοιξε issue με ένα **πραγματικό** παράδειγμα (κείμενο + μοντέλο που το έγραψε). Τα πραγματικά κείμενα από ChatGPT, Gemini και Claude είναι το πιο χρήσιμο υλικό, γιατί έχουν πιο διακριτικά σημάδια από τα συνθετικά.
