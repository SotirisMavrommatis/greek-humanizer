# greek-humanizer

Agent skill που αφαιρεί από **ελληνικά** κείμενα τα σημάδια ότι τα έγραψε AI και τα ξαναγράφει ώστε να διαβάζονται φυσικά, χωρίς να αλλάζει τα γεγονότα.

Τα γνωστά humanizer skills (π.χ. [blader/humanizer](https://github.com/blader/humanizer)) είναι φτιαγμένα για αγγλικά. Τα ελληνικά κείμενα από AI έχουν δικά τους tics: μετοχές στο τέλος της πρότασης («…, ενισχύοντας έτσι…»), γραφειοκρατική σύνταξη («σε ό,τι αφορά», «μέσω της χρήσης»), αλυσίδες γενικών, «ο οποίος / η οποία», αγγλικά εισαγωγικά αντί για «», Title Case στους τίτλους, «διαδραματίζει καθοριστικό ρόλο».

## Εγκατάσταση

**Claude Code**
```bash
npx skills add <user>/greek-humanizer --skill greek-humanizer
```
ή χειροκίνητα:
```bash
git clone https://github.com/<user>/greek-humanizer.git
cp -r greek-humanizer/skills/greek-humanizer ~/.claude/skills/
```

**Claude.ai:** ανέβασε τον φάκελο `skills/greek-humanizer` ως zip από τις ρυθμίσεις Skills.

**Άλλα εργαλεία (ChatGPT, Gemini κ.λπ.):** επικόλλησε το περιεχόμενο του `SKILL.md` στις custom instructions.

## Χρήση

```
/greek-humanizer
[το κείμενο]
```
ή απλά: «Κάνε αυτό το κείμενο να μην ακούγεται σαν AI».

- **Review μόνο:** «Κάνε μόνο review», για λίστα με τα προβληματικά σημεία χωρίς ξαναγράψιμο.
- **Με δείγμα γραφής:** δώσε 2–3 παραγράφους δικές σου, και το skill θα γράψει με το δικό σου ύφος.

## Τι κάνει και τι δεν κάνει

- Δεν προσθέτει γεγονότα. Αν το αρχικό είναι αόριστο, το αποτέλεσμα μένει αόριστο.
- Σέβεται το είδος: απρόσωπη παθητική σε επιστημονικά κείμενα, hashtags σε posts, λίστες σε README.
- Αν το κείμενο είναι ήδη φυσικό, το λέει και δεν το πειράζει.
- Δεν είναι εργαλείο για να ξεγελάσεις AI detectors. Σκοπός είναι το κείμενο να διαβάζεται καλύτερα.

## Δοκιμές

Ο φάκελος [`tests/`](tests/) έχει 12 κείμενα από διαφορετικά είδη: εργασία, email, LinkedIn, README, μήνυμα σε φίλο, περιγραφή προϊόντος, είδηση, τεχνικό, ακαδημαϊκό κ.ά. Για κάθε κείμενο υπάρχει η έξοδος της v1, οι αδυναμίες που βρέθηκαν και η επανάληψη με τη v2.
